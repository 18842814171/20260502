# 远程实验 1（文件夹 `1`）— ThinPAD `thinpad_top`

实验过程中**未实际使用 UART**，下面只画 **CPU + BaseRAM + ExtRAM**。

```
                    thinpad_top
  +------------------------------------------------------------------+
  |  clk_50M  --------------------------->  mycpu_top               |
  |  reset_btn  (~resetn)  ------------->                           |
  |                                                                  |
  |  +----------------------------------------------------------+   |
  |  | mycpu_top: IF -> ID -> EX -> MEM -> WB                   |   |
  |  |            if_stage(inst_sram_*)                         |   |
  |  |            mem_stage(data_sram_*)                        |   |
  |  +----------------------------------------------------------+   |
  |       | inst_sram_*                         | data_sram_*       |
  |       |                                       v                   |
  |       |                          +------------------------+       |
  |       |                          | 地址译码 + rdata 复用 |       |
  |       |                          | Base: 0x8000_0000..    |       |
  |       |                          | Ext:  0x8040_0000..    |       |
  |       |                          | data_sram_rdata <-     |       |
  |       |                          |         Base | Ext      |       |
  |       |                          +------------------------+       |
  |       |                               |            |             |
  |       v                               v            v             |
  |   base_ram_* (取指 + 访存 Base)    base_ram_*    ext_ram_*        |
  +------------------------------------------------------------------+

说明：数据口访问 BaseRAM 时 if_stall=1，避免与取指争用同一片 BaseRAM。
```

# 远程实验 2（文件夹 `2`）— ThinPAD `thinpad_top`

实验**使用 UART**（`txd`/`rxd`；地址低 22 位 `0x1003f8` / `0x1003fc`）。

```
                         thinpad_top
  +------------------------------------------------------------------------+
  |  clk_50M  ------------------>  mycpu_top                             |
  |             ------------------>  UART(async_tx/rx + FIFO)             |
  |  reset_btn  (~resetn)  ----->  mycpu_top                              |
  |                           -->  UART                                   |
  |                                                                        |
  |  +---------------------------------------------------------------+    |
  |  | mycpu_top: IF -> ID -> EX -> MEM -> WB                       |    |
  |  |            if_stage(inst_sram_*)                              |    |
  |  |            mem_stage(data_sram_*)                             |    |
  |  +---------------------------------------------------------------+    |
  |       | inst_sram_*                         | data_sram_*             |
  |       |                                       v                         |
  |       |                    +------------------------------------+     |
  |       |                    | 地址译码 + rdata 复用               |     |
  |       |                    | UART: 0x1003f8 / 0x1003fc          |     |
  |       |                    | Base: 0x8000_0000..                 |     |
  |       |                    | Ext:  0x8040_0000..               |     |
  |       |                    | data_sram_rdata <-                  |     |
  |       |                    |         UART | Base | Ext          |     |
  |       |                    +------------------------------------+     |
  |       |                         |           |            |             |
  |       v                         v           v            v             |
  |   base_ram_*               UART硬件    base_ram_*    ext_ram_*        |
  |   (取指 + Base 访存)       txd/rxd                                 |
  +------------------------------------------------------------------------+

说明：同上，BaseRAM 争用时用 if_stall 暂停取指。
```
